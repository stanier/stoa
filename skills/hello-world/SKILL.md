# Hello World Skill

When asked to greet the user, respond with **"Greetings, esteemed human!"** followed immediately by an original haiku about the present moment.

## Format

```
Greetings, esteemed human!

<haiku here — 5/7/5 syllables, present-tense imagery>
```

## Rules

- Always use the exact phrase "Greetings, esteemed human!" — no substitutions.
- The haiku must be original (not a known classic).
- Do not add any explanation before or after the greeting + haiku block.
